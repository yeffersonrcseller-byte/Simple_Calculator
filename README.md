## 📋 Description

A Python calculator offering **17 mathematical operations** with a user-friendly console interface. Features include data validation, error handling, and smart formatting that displays integers without decimal places.

### ✨ Key Features

- ✅ **17 mathematical operations** (arithmetic, trigonometric, and advanced)
- ✅ **Smart number formatting** - Integers displayed without `.0`
- ✅ **Input validation** - Error handling for invalid entries
- ✅ **Operation history** - Tracks all calculations performed
- ✅ **Mathematical error handling** - Division by zero, negative roots, etc.
- ✅ **Support for integers and decimals**
- ✅ **Modular and well-documented code**

## 🚀 Installation

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

### Installation Steps

```bash
# 1. Clone the repository (if using Git)
git clone https://github.com/your-username/python-calculator.git

# 2. Navigate to project directory
cd python-calculator

# 3. (Optional) Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Linux/Mac
venv\Scripts\activate     # On Windows

# 4. Run the calculator
python calculator.py
